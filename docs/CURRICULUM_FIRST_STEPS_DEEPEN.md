# Curriculum plan: First Steps and Deepen My Knowledge

Journey → Modules → Courses. A journey is a learning path. Modules group courses.
Subjects and difficulty levels describe the course. This plan follows the same
structure as the Explore Islam plan (أتعرف على الإسلام / أتعمق وأجد أجوبة لأسئلتي /
أفهم الإسلام في الحياة) and reuses the existing module IDs in `content/tracks.json`.

Every new course is a `draft` written with AI assistance. Its sources are `pending`
until a scholarly reviewer approves them. Reviewer notes, including the points of
scholarly difference marked **[C]**, are in
[`content/kb/REVIEW_FIRST_STEPS_DEEPEN.md`](../content/kb/REVIEW_FIRST_STEPS_DEEPEN.md).
Existing courses are marked *(existing)*.
